# Upstream Substrait function test cases

These files are a copy of
[substrait-io/substrait `tests/cases`](https://github.com/substrait-io/substrait/tree/v0.107.0/tests/cases)
at **v0.107.0** (commit `edb8d48`), with the fixes listed below: 136 files, 1315 test cases.
Do not edit them by hand — change `FIXES` in `scripts/sync_upstream_function_tests.py` and re-run it.

[tests/README.md](https://github.com/substrait-io/substrait/blob/v0.107.0/tests/README.md).
